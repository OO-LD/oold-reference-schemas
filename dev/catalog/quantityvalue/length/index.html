Length¶

A QuantityValue restricted to length units. It carries no new properties: a subschema in this module exists to constrain, to default, and to say what the quantity is in each community's vocabulary.

  • extends: QuantityValue (allOf)
  • extended by: Diameter
  • module: quantities
  • published at quantities/1.0/Length.schema.json

What it adds¶

addition effect
class term Length -> qkind:Length instances type as the QUDT quantity kind
unit enum M, MilliM, MicroM pins the valid units and guards the @vocab coercion
default M the SI unit, so an instance may omit unit entirely
unit value terms each unit individual is aliasable per community

Alternative readings¶

The class term carries two alternatives, and they are not equivalent in kind:

  • EMMO Length (EMMO_cd2cd0de..., ISO 80000 item 3-1.1) is an exact match: it is the ISQ quantity, the same thing QUDT names.
  • PATO length (PATO_0000122) is only a close match, deliberately. PATO models length as a quality inhering in a bearer, not as a value with a unit. Declaring that exact would assert that a number-with-unit is the same entity as a property of an object, which is the category error the mapping is supposed to expose rather than hide.

Each unit individual also carries its EMMO and UO counterparts, so a community reading resolves the unit itself and not merely the property pointing at it.
