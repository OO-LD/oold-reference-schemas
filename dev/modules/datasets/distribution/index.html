Distribution¶

Where the bytes are, in which format, and which schema they embody.

  • module: datasets 0.1.0
  • schema file: /datasets/dev/Distribution.schema.json

Storage, not content. conforms_to points back at the dataset schema the file is an encoding of, and table_schema at the row schema where the serialisation is tabular, so a reader can materialise rows without guessing. selector addresses one part inside a container: a sheet, an HDF path, a table in a database, a member of an archive.
